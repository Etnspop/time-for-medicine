# 吃藥時間 · Time for Medicine 💊

一個幫你「每天按時吃藥」的小工具。可以輸入你要吃的藥、每天的劑量與時間，
每吃一次就打勾，到時間還會主動跳出提醒。

**所有資料只存在你的手機本機裡（瀏覽器 localStorage），不會上傳到任何伺服器，也不需要註冊或登入。**

這是一個 **PWA（漸進式網頁 App）**：用瀏覽器打開後，可以「加入主畫面」變成像一般 App 一樣，
還能離線使用。

---

## 功能

- 📝 **新增藥物**：輸入名稱、每次劑量（顆／錠／ml／mg…）、一天要吃的時間（可多個）、備註（例如「飯後」）。
- ✅ **每日打勾**：「今日」頁列出今天所有該吃的藥，吃完點一下圓圈打勾；上方進度條顯示今天吃了幾項。
- ⏰ **主動提醒**：點右上角 🔔 開啟通知後，到了服用時間 App 會跳出提醒（已打勾的就不再吵你）。
- 🔁 **未服藥重複提醒**：可在「更多」頁開啟，沒勾選的藥每 4 小時提醒一次，直到你勾選或今天結束（預設開啟）。
- 📡 **背景推播（選用）**：部署一個小後端後，即使 App 完全關閉也能在服藥時間收到通知。後端只存「裝置端點＋服藥時間＋時區」，**不存藥名等個資**。部署教學見 [`server/SETUP.md`](server/SETUP.md)。
- 🗓️ **歷史月曆**：「紀錄」頁用月曆呈現每天的服藥狀況（綠＝全部完成、黃＝部分、紅＝未服用），點任一天可看當天明細。
- 📋 **慢性處方箋領藥提醒**：「處方箋」頁可加入多張慢性病連續處方箋，每張可設定多次領藥區間（例如 06/01～06/15）。到了可領藥的日子，「今日」頁會跳出提醒並發出通知；領完藥點一下標記「已領」即可。
- 💾 **匯出／還原備份**：「更多」頁可把所有資料（含處方箋）匯出成 JSON 檔備份，換手機或清除瀏覽器前先備份，之後再還原。
- 🔁 **每天自動重置**：跨過午夜，今日清單會自動恢復成未服用，方便每天重新追蹤。
- 📶 **離線可用**：第一次載入後沒網路也能用。

> 想要「App 完全關閉也能準時響」？那需要額外的 Web Push 推播伺服器（保管裝置推播端點，但不需存你的藥物資料）；
> iOS 還需 16.4+ 且已「加入主畫面」。或改用匯出 `.ics` 到手機行事曆設鬧鐘——這是唯一不靠伺服器、又能在 App 關閉時響的方式。

## 如何使用

PWA 需要透過網址（http/https）開啟，不能直接用 `file://` 雙擊打開（Service Worker 會無法運作）。

### 在電腦本機試用

```bash
# 在專案資料夾執行（擇一）
python3 -m http.server 8000
#   或
npx serve .
```

然後用瀏覽器打開 <http://localhost:8000>。

### 放到手機上使用

1. 把這個資料夾部署到任何靜態網站空間（例如 GitHub Pages、Netlify、Vercel——都有免費方案）。
2. 用手機瀏覽器打開該網址。
3. 點瀏覽器選單的 **「加入主畫面」／「安裝應用程式」**，之後就能像 App 一樣從桌面打開。
4. 進 App 後點右上角 🔔 允許通知，提醒功能才會生效。

> 提醒的小提醒：網頁 App 的通知在「App 有開著或在背景」時最可靠。
> 若要做到「App 完全關閉也能準時響」，需要額外的推播伺服器（Web Push），
> 這超出「資料只存本機、不連伺服器」的設計範圍，因此目前採用裝置端排程提醒。

## 開發 / 測試

App 本身純前端、不需安裝任何套件即可使用。測試分兩類：

```bash
# 核心邏輯單元測試（不需安裝任何東西）
node --test test/logic.test.js

# 介面 + 功能整合測試（用 jsdom 跑真實 DOM 操作流程，需先安裝 devDependencies）
npm install
npm test          # 等同 node --test，會跑 logic + ui 兩組測試
```

### 專案結構

```
index.html         主畫面（今日 / 紀錄 / 藥物 / 處方箋 / 更多）
css/style.css      樣式（行動裝置優先、Tiffany + 粉色）
js/logic.js        純邏輯（劑量、排序、提醒、月曆、領藥、推播排程彙整）— 可測試
js/app.js          介面與互動、本機儲存、通知排程、推播訂閱
js/push-config.js  背景推播設定（Worker 網址與 VAPID 公鑰，預設為空）
sw.js              Service Worker（離線快取 + 顯示通知 + 接收推播）
manifest.json      PWA 設定
icons/             App 圖示
test/              前端測試（logic + jsdom UI 整合）
server/            背景推播後端（Cloudflare Worker）+ 部署教學 SETUP.md
```

## 隱私

前端沒有帳號、不追蹤；藥物清單與服藥紀錄只寫進你裝置上的瀏覽器儲存空間。
背景推播（選用）的後端也只存「裝置端點＋服藥時間＋時區」，不含藥名等個資。
