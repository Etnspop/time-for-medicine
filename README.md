# 吃藥時間 · Time for Medicine 💊

一個幫你「每天按時吃藥」的小工具。可以輸入你要吃的藥、每天的劑量與時間，
每吃一次就打勾，到時間還會主動跳出提醒。

**所有資料只存在你的手機本機裡（瀏覽器 localStorage），不會上傳到任何伺服器，也不需要註冊或登入。**

這是一個 **PWA（漸進式網頁 App）**：用瀏覽器打開後，可以「加入主畫面」變成像一般 App 一樣，
還能離線使用。

---

## 功能

- 📝 **新增藥物**：輸入名稱、每次劑量（顆／錠／ml／mg…）、一天要吃的時間（可多個）、備註（例如「飯後」）。
- ✅ **每日打勾**：「今日」頁列出今天所有該吃的藥，吃完點一下圓圈打勾；上方進度條顯示今天吃了幾項。
- ⏰ **主動提醒**：點右上角 🔔 開啟通知後，到了服用時間 App 會跳出提醒（提醒過、或已打勾的就不再吵你）。
- 🗓️ **歷史月曆**：「紀錄」頁用月曆呈現每天的服藥狀況（綠＝全部完成、黃＝部分、紅＝未服用），點任一天可看當天明細。
- 📦 **補藥提醒**：可選填藥物剩餘數量與「低於幾天提醒」，每次打勾自動扣庫存；快用完時「今日」頁會跳出補藥橫幅並通知你。
- 💾 **匯出／還原備份**：「更多」頁可把所有資料匯出成 JSON 檔備份，換手機或清除瀏覽器前先備份，之後再還原。
- 🔁 **每天自動重置**：跨過午夜，今日清單會自動恢復成未服用，方便每天重新追蹤。
- 📶 **離線可用**：第一次載入後沒網路也能用。

> 想要「App 完全關閉也能準時響」？那需要額外的 Web Push 推播伺服器（保管裝置推播端點，但不需存你的藥物資料）；
> iOS 還需 16.4+ 且已「加入主畫面」。或改用匯出 `.ics` 到手機行事曆設鬧鐘——這是唯一不靠伺服器、又能在 App 關閉時響的方式。

## 如何使用

PWA 需要透過網址（http/https）開啟，不能直接用 `file://` 雙擊打開（Service Worker 會無法運作）。

### 在電腦本機試用

```bash
# 在專案資料夾執行（擇一）
python3 -m http.server 8000
#   或
npx serve .
```

然後用瀏覽器打開 <http://localhost:8000>。

### 放到手機上使用

1. 把這個資料夾部署到任何靜態網站空間（例如 GitHub Pages、Netlify、Vercel——都有免費方案）。
2. 用手機瀏覽器打開該網址。
3. 點瀏覽器選單的 **「加入主畫面」／「安裝應用程式」**，之後就能像 App 一樣從桌面打開。
4. 進 App 後點右上角 🔔 允許通知，提醒功能才會生效。

> 提醒的小提醒：網頁 App 的通知在「App 有開著或在背景」時最可靠。
> 若要做到「App 完全關閉也能準時響」，需要額外的推播伺服器（Web Push），
> 這超出「資料只存本機、不連伺服器」的設計範圍，因此目前採用裝置端排程提醒。

## 開發 / 測試

純前端，無需安裝套件。核心邏輯有單元測試：

```bash
node --test test/logic.test.js
```

### 專案結構

```
index.html        主畫面（今日 / 我的藥物 兩個分頁）
css/style.css     樣式（行動裝置優先）
js/logic.js       純邏輯（劑量計算、排序、提醒判斷）— 瀏覽器與 Node 共用、可測試
js/app.js         介面與互動、本機儲存、通知排程
sw.js             Service Worker（離線快取 + 顯示通知）
manifest.json     PWA 設定（圖示、名稱、主題色）
icons/            App 圖示
test/             單元測試
```

## 隱私

沒有帳號、沒有後端、沒有追蹤。藥物清單與服藥紀錄只寫進你裝置上的瀏覽器儲存空間，
清除瀏覽器資料即會一併刪除。
